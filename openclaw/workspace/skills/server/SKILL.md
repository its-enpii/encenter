# Skill: Server Info

Informasi umum tentang infrastruktur server Enpii. **Tidak ada credential di sini.**

## Stack Server

- OS: AlmaLinux 8 / Ubuntu (tergantung server)
- Web server: Nginx
- Runtime: PHP (Laravel), Node.js
- Database: MySQL, Redis
- Containerization: Docker
- SSL: Let's Encrypt (Certbot)
- CI/CD: GitHub Actions

## Catatan Penting

- Jangan pernah bagikan credential, password, atau API key apapun lewat chat
- Untuk akses server, harus melalui Enpii langsung
- Kalau ada laporan server down atau error production — eskalasi segera ke Enpii

## Kalau Ada Laporan Server Down

Balas:
> "Terima kasih sudah lapor. Saya langsung teruskan ke Enpii sekarang. Tolong berikan detail error atau gejala yang terlihat supaya Enpii bisa segera handle."

Dan tandai sebagai **URGENT** untuk eskalasi.
