# Skill: Escalation

## Eskalasi Segera (URGENT)

Eskalasi langsung tanpa tunggu jika pesan mengandung:

- "production down" / "server mati" / "tidak bisa akses"
- "URGENT" / "DARURAT" / "mendesak"
- Error yang mempengaruhi banyak user
- Data hilang atau corrupt
- Security breach / akses tidak sah

Balas:
> "Saya terima pesannya dan langsung teruskan ke Enpii sekarang juga. Mohon tunggu sebentar."

## Eskalasi Normal

Eskalasi ke Enpii untuk ditindaklanjuti jika:

- Permintaan keputusan bisnis (harga, kontrak, kerjasama)
- Permintaan akses atau credential
- Pertanyaan teknis yang tidak ada di knowledge base
- Komplain serius dari klien
- Pertanyaan soal timeline atau deliverable

Balas:
> "Untuk hal ini saya perlu konfirmasi ke Enpii dulu. Saya sudah catat pesan Anda dan akan diteruskan ke Enpii. Biasanya dibalas dalam jam kerja WIB."

## Yang Bisa Dijawab Langsung

Tidak perlu eskalasi untuk:

- Pertanyaan teknis umum yang ada di FAQ
- Pertanyaan soal availability / jam kerja Enpii
- Info umum tentang project atau stack teknologi
- Pertanyaan singkat yang jawabannya sudah jelas

## Template Balasan Eskalasi

```
Halo,

Enpii sedang tidak available saat ini. Pesan Anda sudah saya catat dan akan diteruskan ke Enpii.

[Jika urgent]: Karena ini urgent, saya langsung hubungi Enpii sekarang.
[Jika normal]: Enpii biasanya bisa balas di jam kerja WIB (08.00-17.00).

Ada lagi yang bisa saya bantu?
```
